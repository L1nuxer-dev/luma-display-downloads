# Luma Display — downloads

Luma Display turns an Android phone or tablet into a real second monitor for a
Windows PC. It comes in two halves:

| | |
|---|---|
| **The app** | [Google Play](https://play.google.com/store/apps/details?id=dev.l1nuxer.luma) |
| **The Windows host** | [Latest release](../../releases/latest) — free, and required |

The app cannot work on its own. Install the host on a Windows 10 or 11 PC,
then connect your device by USB cable or over the same Wi-Fi network.

## Installing the host

1. Download `LumaDisplaySetup.exe` from the [latest release](../../releases/latest).
2. Run it. Windows may warn that the publisher is unknown — the installer is
   not yet code-signed. Choose **More info** then **Run anyway**.
3. The installer sets up a virtual display driver, allows the two ports it uses
   through the firewall, and puts an icon in the notification area.
4. Open the app on your device. Over Wi-Fi the PC shows a six-digit pairing
   code the first time; enter it once and the device reconnects on its own
   afterwards.

## What it needs

- Windows 10 or 11
- An Android device on the same network, or a USB cable
- For the cable: allowing USB debugging on the device once. The host says so
  plainly when that is what is missing.

## Trying it, and buying it

The host runs in trial mode until it is licensed: sessions last 15 minutes, and
restarting it starts a fresh one. Everything works during the trial — the limit
is on session length, not on features. The full version is bought once, through
the app.
